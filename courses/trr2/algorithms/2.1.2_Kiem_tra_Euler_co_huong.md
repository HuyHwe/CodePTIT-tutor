# 2.1.2. Kiểm tra đồ thị Euler / nửa Euler – Đồ thị có hướng

**Lời văn.**
1. Kiểm tra liên thông yếu: gọi DFS(1) đi theo cả hai chiều cạnh (coi như đồ thị vô hướng tương ứng); còn đỉnh chưa thăm thì kết luận không phải Euler, dừng.
2. Tính bậc từ ma trận kề: deg+(u) = tổng hàng u; deg−(u) = tổng cột u. Đặt d(u) = deg+(u) − deg−(u).
3. Đối chiếu bảng dưới để kết luận.

| Điều kiện trên d(u) | Kết luận |
|---|---|
| Mọi đỉnh d(u) = 0 (deg+ = deg−) | Euler (có chu trình Euler) |
| Đúng 1 đỉnh d = +1 (điểm đầu), đúng 1 đỉnh d = −1 (điểm cuối), còn lại d = 0 | Nửa Euler (có đường đi Euler từ điểm đầu đến điểm cuối) |
| Khác (có đỉnh d ∉ {0, ±1}, hoặc số đỉnh +1 / −1 không đúng 1 và 1) | Không phải Euler, không phải nửa Euler |

**Mã giả.**
```text
ktEulerCH():
    DFS(1) đi cả 2 chiều
    if còn đỉnh chưa thăm: return 0        // không liên thông yếu
    ra = 0, vao = 0
    for u in V:
        d = deg+(u) − deg−(u)
        if d == 1: ra++
        else if d == −1: vao++
        else if d != 0: return 0
    if ra == 0 and vao == 0: return 1      // Euler
    if ra == 1 and vao == 1: return 2      // nửa Euler
    return 0
```

Ở bản vô hướng, DFS chỉ cần a[u][v] vì ma trận đã đối xứng. Ở bản có hướng, phải dùng a[u][v] || a[v][u] để xét liên thông yếu.
