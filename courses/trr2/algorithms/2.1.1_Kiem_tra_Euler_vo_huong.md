# 2.1.1. Kiểm tra đồ thị Euler / nửa Euler – Đồ thị vô hướng

> Chương 2 – Chu trình Euler và chu trình Hamilton
>
> Euler = đi qua mỗi cạnh đúng một lần, có điều kiện nhận biết và thuật toán ngăn xếp O(n·m). Hamilton = đi qua mỗi đỉnh đúng một lần, chưa có tiêu chuẩn nhận biết nên chỉ có cách quay lui duyệt toàn bộ.

**Lời văn.**
1. Kiểm tra liên thông: gọi DFS(1); còn đỉnh chưa thăm thì kết luận không phải Euler, dừng.
2. Tính bậc mỗi đỉnh từ ma trận kề: deg(u) = tổng hàng u. Đếm số đỉnh bậc lẻ.
3. Đối chiếu bảng dưới để kết luận.

| Số đỉnh bậc lẻ | Kết luận |
|---|---|
| 0 (mọi đỉnh bậc chẵn) | Euler (có chu trình Euler) |
| 2 | Nửa Euler (có đường đi Euler, nối đúng 2 đỉnh bậc lẻ đó) |
| Khác | Không phải Euler, không phải nửa Euler |

**Mã giả.**
```text
ktEulerVH():
    DFS(1)
    if còn đỉnh chưa thăm: return 0        // không liên thông
    le = 0
    for u in V:
        if deg(u) lẻ: le++
    if le == 0: return 1                   // Euler
    if le == 2: return 2                   // nửa Euler
    return 0
```
