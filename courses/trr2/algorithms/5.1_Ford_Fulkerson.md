# 5.1. Ford-Fulkerson (tìm đường tăng luồng bằng BFS)

> Chương 5 – Luồng cực đại: Ford-Fulkerson và lát cắt hẹp nhất
>
> Lặp lại: tìm một đường tăng luồng từ s đến t trên đồ thị tăng luồng, rồi đẩy thêm δ = cạnh nhỏ nhất trên đường đó. Hết đường tăng luồng thì luồng đang có là cực đại, và giá trị của nó bằng khả năng thông qua của lát cắt hẹp nhất.

**Lời văn.**
1. Khởi tạo luồng 0, val = 0. Đồ thị tăng luồng Gf lưu trong a[u][v] = lượng còn đẩy thêm được từ u sang v; ban đầu chính là khả năng thông qua c(u, v).
2. Lặp:
   1. BFS từ s trên các cung có a[u][v] > 0, ghi truoc[]. Không tới được t thì dừng.
   2. Lần ngược từ t về s, lấy δ = min các a[truoc[v]][v] trên đường.
   3. Tăng luồng dọc đường: cung thuận a[u][v] -= δ, cung nghịch a[v][u] += δ; cộng δ vào val.
3. Trả về val(f); luồng trên cung gốc (u, v) = c(u, v) − a[u][v].
Đây đúng là 3 quy tắc dựng Gf trong slide: f = 0 thì cung thuận trọng số c; f = c thì chỉ có cung nghịch trọng số c; 0 < f < c thì có cung thuận c − f và cung nghịch f. Code gộp cả ba vào hai phép -= δ và += δ.

**Mã giả.**
```text
FordFulkerson(s, t):
    f = 0; val = 0
    while (P = BFS(s) tìm được đường s → t trên Gf):
        δ = min trọng số cung trên P
        for (u,v) in P:
            if (u,v) là cung thuận: f(u,v) += δ
            else:                    f(v,u) -= δ
        val += δ; cập nhật Gf
    return val
```
