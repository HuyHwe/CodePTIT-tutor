# 2.3. Liệt kê chu trình Hamilton (quay lui)

**Lời văn.**
1. Khởi tạo mọi đỉnh chưa xét; đặt X[1] = v0, đánh dấu v0, gọi Hamilton(2).
2. Hamilton(k): lần lượt thử mọi đỉnh y kề với X[k − 1]:
   1. Nếu k = n + 1 và y = v0: đã khép được chu trình, ghi nhận X[1..n], v0.
   2. Ngược lại, nếu y chưa xét: đặt X[k] = y, đánh dấu y, gọi Hamilton(k + 1).
   3. Gọi xong thì bỏ đánh dấu y (quay lui) để thử đỉnh y khác.

**Mã giả.**
```text
Hamilton(k):
    for y in Ke(X[k−1]):
        if k == n+1 and y == v0: Ghinhan(X[1..n], v0)
        else if !vs[y]:
            X[k] = y; vs[y] = 1
            Hamilton(k+1)
            vs[y] = 0
Hamilton-Cycle(v0):  vs[] = 0; X[1] = v0; vs[v0] = 1; Hamilton(2)
```
