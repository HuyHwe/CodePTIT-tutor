# 1.7. Kiểm tra liên thông mạnh (đồ thị có hướng) - Không khuyến khích dùng cách này, chạy rất lâu dễ bị TLE

**Lời văn.**
1. Lặp với mỗi đỉnh u:
   1. Xóa đánh dấu (ReInit).
   2. Chạy DFS(u), đếm số đỉnh thăm được.
   3. Nếu thăm được ít hơn n đỉnh: kết luận không liên thông mạnh, dừng.
2. Qua được hết n lần: kết luận liên thông mạnh.

**Mã giả.**
```text
for u in V:
    ReInit()  // vs[] = 0
    if DFS(u) ≠ V: return false
return true
```
