# 3.3. Floyd

**Lời văn.**
1. Khởi tạo với mọi cặp (i, j): d[i][j] = a[i][j]; p[i][j] = i nếu có cạnh i → j, ngược lại p[i][j] = 0.
2. Lặp k = 1→n (vòng k nằm ngoài cùng), với mọi cặp (i, j):
   1. So sánh đường hiện tại d[i][j] với đường đi vòng qua k: d[i][k] + d[k][j].
   2. Nếu đi vòng qua k ngắn hơn: d[i][j] = d[i][k] + d[k][j], p[i][j] = p[k][j].
3. Có d[i][i] < 0 thì đồ thị có chu trình âm.
4. Truy đường i → j: bắt đầu x = j, lặp ghi x rồi gán x = p[i][x] cho đến khi x = i; ghi i, đảo ngược.

**Mã giả.**
```text
Floyd():
    for i, j: d[i][j] = a(i,j); p[i][j] = (a(i,j) ≠ ∞ ? i : null)
    for k = 1→n:
        for i = 1→n:
            for j = 1→n:
                if d[i][j] > d[i][k] + d[k][j]:
                    d[i][j] = d[i][k] + d[k][j]; p[i][j] = p[k][j]
InDuong(u, v):  x = v; while x ≠ u: <ghi x>; x = p[u][x]
                <ghi u>; đảo ngược
```
