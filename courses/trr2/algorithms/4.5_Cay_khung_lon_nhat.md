# 4.5. Cây khung lớn nhất

**Lời văn.**
1. Giữ nguyên thuật toán, chỉ đảo chiều so sánh để luôn ưu tiên cạnh lớn nhất.
2. Kruskal: sắp xếp cạnh giảm dần, thay dòng sort bằng sort(E.rbegin(), E.rend());.
3. Prim (trọng số dương, 0 = không có cạnh): bỏ doiINF(); đổi d[v] < d[u] thành d[v] > d[u], d[u] == INF thành d[u] == 0, a[u][v] < d[v] thành a[u][v] > d[v].

(Mục này không có file .cpp riêng: sửa từ [4.3_Kruskal.cpp](4.3_Kruskal.cpp) / [4.4_Prim.cpp](4.4_Prim.cpp).)
