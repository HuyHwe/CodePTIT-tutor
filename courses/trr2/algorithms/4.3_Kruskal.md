# 4.3. Kruskal (cây khung nhỏ nhất, theo cạnh)

Lưu ý: Cách diễn giải và code dưới đây sử dụng ý tưởng của thuật toán DSU (Disjoint set union). Có những cách khác không cần dùng DSU để code, dễ hiểu hơn nhưng anh thấy code dài và dễ sai hơn. Các bạn nên nắm được idea của thuật toán DSU trước khi đọc nhé.

**Lời văn.**
1. Khởi tạo T = ∅, d(T) = 0
2. Sắp xếp các cạnh theo trọng số tăng dần.
3. Lặp lần lượt từng cạnh (u, v), cho đến khi T đủ n − 1 cạnh hoặc hết cạnh:
   1. Tìm gốc cây chứa u và v: x = Find(u), y = Find(v).
   2. Nếu x = y: thêm cạnh sẽ tạo chu trình, bỏ qua.
   3. Nếu x ≠ y: kết nạp (u, v) vào T, cộng trọng số vào d(T), nối hai cây (par[x] = y).
4. Nếu |T| < n − 1: đồ thị không liên thông; ngược lại trả về T và d(T).

**Mã giả.**
```text
Kruskal():
    T = ∅; dT = 0
    sắp xếp E tăng dần theo trọng số
    for e = (u,v) in E, khi |T| < n−1:
        // Find(u) ≠ Find(v)
        if T ∪ {e} không tạo chu trình:
            T = T ∪ {e}; dT += w(e)
    if |T| < n−1: <không liên thông> else return (T, dT)
```

Nhập ma trận trọng số, 0 = không có cạnh

**Lưu ý cho bài CodePTIT TRR4007:** đề cho **danh sách cạnh** `u v w` (code mẫu ở trên nhập ma trận). Khi nhiều cạnh cùng trọng số, đáp án xét theo (w, u, v) tăng dần.
