# 1.4. Đếm và liệt kê thành phần liên thông

**Lời văn.**
1. Khởi tạo soTPLT = 0, mọi đỉnh chưa xét.
2. Duyệt lần lượt u = 1..n:
   1. Nếu u chưa xét: tăng soTPLT thêm 1, gọi DFS(u) (hoặc BFS(u)).
   2. Các đỉnh lần gọi này thăm được thuộc cùng một TPLT.
3. Trả về soTPLT và các TPLT.

**Mã giả.**
```text
soTPLT = 0
for u in V:
    // các đỉnh vừa thăm = 1 TPLT
    if !vs[u]: soTPLT++; DFS(u)
```
