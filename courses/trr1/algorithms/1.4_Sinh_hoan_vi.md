# 1.4. Sinh hoán vị của 1..n

**Lời văn.**
1. Cấu hình đầu tiên là (1, 2, …, n), cấu hình cuối cùng là (n, n − 1, …, 1).
2. Sinh cấu hình kế tiếp:
   1. Duyệt từ phải sang trái, tìm vị trí i đầu tiên có X[i] < X[i + 1] (số nhỏ hơn số ngay bên phải nó)
   2. Không tìm được (i = 0): dãy đang giảm dần, đã là cấu hình cuối, dừng.
   3. Trong đoạn từ i đổ về sau, tìm X[j] là số nhỏ nhất mà lớn hơn X[i].
   4. Đổi chỗ X[i] và X[j].
   5. Lật ngược đoạn X[i + 1..n].

**Mã giả.**
```text
Sinh():
    i = n − 1
    while (i ≥ 1 and X[i] > X[i+1]): i--
    if (i == 0): return false
    j = n
    while (X[j] < X[i]): j--
    swap(X[i], X[j])
    lật ngược X[i+1 .. n]
    return true
Main: X = (1, 2, ..., n); do { Result(); } while (Sinh())
```
