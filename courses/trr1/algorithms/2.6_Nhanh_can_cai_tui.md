# 2.6. Nhánh cận: cái túi 0/1

**Lời văn.**
1. Sắp xếp đồ vật theo v[i]/w[i] giảm dần (giữ lại chỉ số gốc để in kết quả).
2. FOPT = 0, delta = 0 (tổng giá trị đã lấy), b là trọng lượng còn lại của túi.
3. Try(k): lần lượt thử x[k] = 1 rồi x[k] = 0, bỏ qua nếu đồ vật không vừa túi:
   1. Cập nhật δ += v[k]·x[k], b −= w[k]·x[k].
   2. Nếu k = n: δ > FOPT thì cập nhật FOPT, XOPT.
   3. k != n thì tính cận trên g = δ + b·v[k+1]/w[k+1]. Chỉ gọi Try(k + 1) khi g > FOPT.
   4. Hoàn trả delta và b.
4. In FOPT và XOPT theo thứ tự đồ vật ban đầu.

**Mã giả.**
```text
Try(k):
    for j = 1 down to 0:
        if (j·w[k] > b): continue
        x[k] = j; delta += j·v[k]; b −= j·w[k]
        if (k == n):
            if (delta > FOPT): FOPT = delta; XOPT = x
        elif (delta + b·v[k+1]/w[k+1] > FOPT): Try(k + 1)
        delta −= j·v[k]; b += j·w[k]
Main: sắp xếp v/w giảm dần; FOPT = 0; delta = 0; Try(1)
```
