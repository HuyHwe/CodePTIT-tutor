# 2.8. Nhánh cận: phân việc

**Lời văn.**
1. Tính cmin = phần tử nhỏ nhất của ma trận thời gian. FOPT = +∞, delta = 0.
2. Try(i): lần lượt thử việc j = 1..n chưa giao cho ai:
   1. Gán x[i] = j, đánh dấu j, delta += c[i][j].
   2. Nếu i = n: delta < FOPT thì cập nhật FOPT, XOPT.
   3. Ngược lại tính cận dưới g = delta + (n − i)·cmin (còn n − i người chưa giao việc, mỗi người tốn ít nhất cmin). Chỉ gọi Try(i + 1) khi g < FOPT.
   4. Bỏ đánh dấu j, delta −= c[i][j].
3. In FOPT và cách giao việc XOPT.

**Mã giả.**
```text
Try(i):
    for j = 1 to n:
        if (!vs[j]):
            x[i] = j; vs[j] = 1; delta += c[i][j]
            if (i == n):
                if (delta < FOPT): FOPT = delta; XOPT = x
            elif (delta + (n − i)·cmin < FOPT): Try(i + 1)
            vs[j] = 0; delta −= c[i][j]
Main: cmin = min c[i][j]; FOPT = +∞; Try(1)
```
