# 1.7. Quay lui tổ hợp chập k của n

**Lời văn.**
1. Coi X[0] = 0, gọi Try(1).
2. Try(i): lần lượt thử X[i] = j với j chạy từ X[i − 1] + 1 đến n − k + i (giữ dãy tăng dần và còn đủ chỗ cho các phần tử sau):
   1. Nếu i = k: in cấu hình.
   2. Ngược lại: gọi Try(i + 1).

**Mã giả.**
```text
Try(i):
    for j = X[i−1] + 1 to n − k + i:
        X[i] = j
        if (i == k): Result()
        else: Try(i + 1)
Main: X[0] = 0; Try(1)
```
