# 2.7. Nhánh cận: người du lịch

**Lời văn.**
1. Tính cmin = chi phí nhỏ nhất trong ma trận (bỏ đường chéo). FOPT = +∞, delta = 0; cố định x[1] = 1.
2. Try(k): lần lượt thử thành phố j = 2..n chưa đi:
   1. Gán x[k] = j, đánh dấu, delta += c[x[k−1]][j].
   2. Nếu k = n: tổng hành trình = delta + c[j][1]; nhỏ hơn FOPT thì cập nhật.
   3. Ngược lại tính cận dưới g = delta + (n − k + 1)·cmin (còn n − k + 1 đoạn đường, mỗi đoạn tốn ít nhất cmin). Chỉ gọi Try(k + 1) khi g < FOPT.
   4. Bỏ đánh dấu j, delta −= c[x[k−1]][j].
3. In FOPT và hành trình XOPT → 1.

**Mã giả.**
```text
Try(k):
    for j = 2 to n:
        if (!vs[j]):
            x[k] = j; vs[j] = 1; delta += c[x[k−1]][j]
            if (k == n):
                if (delta + c[j][1] < FOPT): FOPT = delta + c[j][1]; XOPT = x
            elif (delta + (n − k + 1)·cmin < FOPT): Try(k + 1)
            vs[j] = 0; delta −= c[x[k−1]][j]
Main: cmin = min c[i][j] (i ≠ j); FOPT = +∞; x[1] = 1; vs[1] = 1; Try(2)
```
