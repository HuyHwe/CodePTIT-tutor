# 1.6. Quay lui xâu nhị phân độ dài n

**Lời văn.**
1. Gọi Try(1).
2. Try(i): lần lượt thử X[i] = 0 rồi X[i] = 1:
   1. Nếu i = n: in cấu hình.
   2. Ngược lại: gọi Try(i + 1).

**Mã giả.**
```text
Try(i):
    for j = 0 to 1:
        X[i] = j
        if (i == n): Result()
        else: Try(i + 1)
Main: Try(1)
```
