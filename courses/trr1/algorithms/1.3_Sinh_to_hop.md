# 1.3. Sinh tổ hợp chập k của n

**Lời văn.**
1. Cấu hình đầu tiên là (1, 2, …, k), cấu hình cuối cùng là (n − k + 1, …, n).
2. Sinh cấu hình kế tiếp:
   1. Duyệt từ phải sang trái, tìm vị trí i đầu tiên có X[i] < n − k + i (chưa đạt giá trị lớn nhất).
   2. Không tìm được (i = 0): đã là cấu hình cuối, dừng.
   3. Tăng X[i] thêm 1.
   4. Các phần tử sau i nối tiếp tăng dần: X[j] = X[i] + (j − i) với j = i + 1..k.

**Mã giả.**
```text
Sinh():
    i = k
    while (i ≥ 1 and X[i] == n − k + i): i--
    if (i == 0): return false
    X[i]++
    for j = i+1 to k: X[j] = X[i] + j − i
    return true
Main: X = (1, 2, ..., k); do { Result(); } while (Sinh())
```
