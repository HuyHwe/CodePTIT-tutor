# 1.8. Quay lui hoán vị của 1..n

**Lời văn.**
1. Mọi số chưa dùng (vs[j] = 0), gọi Try(1).
2. Try(i): lần lượt thử j = 1..n, chỉ nhận j chưa dùng:
   1. Gán X[i] = j, đánh dấu j đã dùng.
   2. Nếu i = n: in cấu hình. Ngược lại: gọi Try(i + 1).
   3. Bỏ đánh dấu j (quay lui) để các vị trí khác còn dùng được j.

**Mã giả.**
```text
Try(i):
    for j = 1 to n:
        if (!vs[j]):
            X[i] = j; vs[j] = 1
            if (i == n): Result()
            else: Try(i + 1)
            vs[j] = 0
Main: vs[] = 0; Try(1)
```
