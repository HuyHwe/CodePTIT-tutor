# 1.5. Thuật toán quay lui (khung chung)

**Lời văn.**
1. Gọi Try(1) để xác định thành phần đầu tiên.
2. Try(i): lần lượt thử từng khả năng j của thành phần X[i]:
   1. Nếu j được chấp thuận: gán X[i] = j (và đánh dấu nếu cần).
   2. Nếu i là thành phần cuối cùng: ghi nhận cấu hình. Ngược lại: gọi Try(i + 1).
   3. Bỏ đánh dấu j (quay lui) để thử khả năng tiếp theo.

**Mã giả.**
```text
Try(i):
    for j = <khả năng 1> to <khả năng cuối>:
        if (<chấp thuận j>):
            X[i] = j; <đánh dấu j>
            if (i == n): Result()
            else: Try(i + 1)
            <bỏ đánh dấu j>
```
