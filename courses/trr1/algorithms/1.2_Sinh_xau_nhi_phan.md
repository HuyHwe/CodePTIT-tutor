# 1.2. Sinh xâu nhị phân độ dài n

**Lời văn.**
1. Cấu hình đầu tiên là 00…0, cấu hình cuối cùng là 11…1.
2. Sinh cấu hình kế tiếp:
   1. Duyệt từ phải sang trái, gặp số 1 thì đổi thành 0 cho đến khi gặp số 0 đầu tiên.
   2. Không gặp số 0 nào (i = 0): đã là cấu hình cuối, dừng.
   3. Đổi số 0 vừa gặp thành 1.

**Mã giả.**
```text
Sinh():
    i = n
    while (i ≥ 1 and X[i] == 1): X[i] = 0; i--
    if (i == 0): return false  // cấu hình cuối
    X[i] = 1; return true
Main: X = 00...0; do { Result(); } while (Sinh())
```
