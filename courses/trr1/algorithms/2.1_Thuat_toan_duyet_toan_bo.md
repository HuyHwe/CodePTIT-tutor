# 2.1. Thuật toán duyệt toàn bộ (khung chung)

**Lời văn.**
1. Khởi tạo XOPT = ∅; FOPT = −∞ (bài toán max) hoặc +∞ (bài toán min).
2. Lặp với mỗi phương án X thuộc tập phương án D (liệt kê bằng quay lui):
   1. Tính giá trị hàm mục tiêu S = f(X).
   2. Nếu S tốt hơn FOPT: FOPT = S, XOPT = X.
3. Trả về XOPT và FOPT.

**Mã giả.**
```text
DuyetToanBo():
    XOPT = ∅; FOPT = −∞ (hoặc +∞)
    for X in D:
        S = f(X)
        if (S tốt hơn FOPT): FOPT = S; XOPT = X
    return (XOPT, FOPT)
```
